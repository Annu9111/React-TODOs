# React Todo List

A modern and responsive Todo List application built with React.js.  
This project was created to practice React Context API, reusable components, state management, localStorage, and CRUD operations.

## About The Project

This Todo List application allows users to easily manage their daily tasks.

Users can:

- Add new todos
- Edit existing todos
- Mark todos as completed
- Delete todos
- Persist todos using browser localStorage
- Manage application state using React Context API

The main goal of this project was not only to build a Todo application, but also to understand how React handles shared state and how multiple components can communicate without passing props through every component.

---

## Features

### Add Todo
Users can enter a task and add it to the Todo List.

### Edit Todo
Existing tasks can be edited whenever needed.

### Complete Todo
Users can mark tasks as completed using a checkbox.

### Delete Todo
Unwanted tasks can be removed from the list.

### Local Storage
Todos are stored in the browser's localStorage, so the tasks remain available even after refreshing the page.

### Context API
The project uses React Context API to share Todo data and functions across components without prop drilling.

### Responsive UI
The interface is built with Tailwind CSS and adapts to different screen sizes.
